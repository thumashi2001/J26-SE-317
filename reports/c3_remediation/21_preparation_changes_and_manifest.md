## 2. Fail-closed safeguard for the browser/API scripts
New `reports/c3_remediation/ui_tests/guard.mjs` (126 lines), imported first by `e2e.mjs`, `functional.mjs`, `capture.mjs` and `ui.mjs`; exit code 2 on any failure; no default database; no fallback to `backend/.env`; nothing dropped or reset.
- **Environment checks (no network):** `C3_TEST_DB` must match `^adaptivelearnse_c3_[a-z0-9_]{2,40}$` (`adaptivelearnse_dev` and similar are refused); `C3_TEST_MONGO_URI` must be `mongodb://`, loopback hosts only, no credentials (`mongodb+srv` refused); `C3_API_BASE` / `C3_WEB_BASE` must be loopback `http://`; `C3_TEST_PASSWORD` required and never printed.
- **Isolation proof before the first write (`verifyIsolation`):** the local database must contain the seeded test student; a **canary student** (random `IT99xxxxxx` id, random password, scrypt hash in the backend's format) is inserted into that database only; the guard logs in as the canary through the backend; the canary is always removed. A backend that is unreachable or reads another database does not know the canary, so the run is refused. **Design change prompted by review:** the first version logged in as the real test student, which would have sent a real account's login to a mis-started backend before the database was proven; the canary removes that. Remaining limitation (documented in the README): the guard cannot see how the backend was started; a backend started without explicit local `MONGO_URI`/`MONGO_DB` uses `backend/.env`, is refused afterwards, but has already received one failed lookup of a random non-existent id. Always start it with explicit local variables.
- Repository-relative driver loading (`../../../backend/package.json`, `C3_BACKEND_DIR` override for copied scripts) replaces the absolute machine path; the Chrome path is overridable with `C3_CHROME_PATH`.
- `ui_tests/README.md` rewritten: prerequisites, the variable table, failure conditions, how to run.
- `ui_tests/guard.test.mjs`: 9 service-free tests (missing variables, bad/dev database names, SRV/remote/credentialed URIs, non-loopback URLs, password never printed).
