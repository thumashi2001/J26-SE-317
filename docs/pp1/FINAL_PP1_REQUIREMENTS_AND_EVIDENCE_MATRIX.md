## 3. Scope Confirmation on Supervisor Directive COM-07

The exact language of supervisor directive **COM-07** states:
> *"Do not present uncalibrated zero-shot LLM numbers during PP1 if parameters are not yet tuned."*

### Authoritative Interpretation:
1. **Conditions A & B (Generative LLMs):** Direct zero-shot LLM calls without systematic hyperparameter calibration (temperature tuning, top_p calibration, few-shot prompt versioning) are forbidden from being presented as primary evaluation numbers during PP1. Offline harnesses are prepared, but live batch evaluations are scheduled for Phase 4.
2. **Condition C (Vector-RAG):** Requires digitized lecture slide embeddings across all 4 modules. Scheduled for post-PP1 Phase 4.
3. **Condition D (GraphRAG):** Blocked because team-wide Neo4j CCKG is unpopulated/unimplemented ("Proposed Architecture Only").
4. **Conditions E & F:** Condition E (Deterministic Rubric Evaluator) is the **active, demonstrable, authoritative primary prototype**. Condition F (Supervised Semantic Regressor) satisfies the explicit **model trainability** requirement.
