# AdaptiveLearnSE C3 — FINAL Development Dataset v5

Canonical C3 dataset for development and controlled experiments.

167 questions / 1,002 controlled answers / 6 variants per question.
Train 117/702, validation 25/150, test 25/150.
71 researcher-designed replacement questions / 426 replacement answers.

Scope: text-based short-answer and essay-answer automated assessment.
All obvious diagram/code-dependent tasks were removed from the final text-focused pool.
The original 63-question replacement audit is preserved; additional scope exceptions found
in the final scan were also converted to written conceptual questions.

This is researcher-constructed controlled data, not authentic student data. The reference
standard is not described as an expert gold standard because independent lecturer/expert
validation has not been obtained.
